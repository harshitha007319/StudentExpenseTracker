# 💰 Student Expense Tracker

A simple and user-friendly web application designed to help students manage their daily expenses, track spending habits, and maintain a monthly budget.

## ✨ Features

* 🔐 Login and Signup
* 💵 Add, Edit, and Delete Expenses
* 📊 Visual Expense Charts
* 🎯 Monthly Budget Management
* 🔍 Search and Filter Expenses
* 📥 Export Expenses to CSV
* 📄 Download Monthly Reports as PDF
* 💡 Spending Insights and Saving Tips
* 🌙 Dark Mode and Light Mode
* 📱 Responsive Design

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Chart.js
* jsPDF
* Browser Local Storage

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `login.html` in your web browser.
4. Sign up or log in to access the expense tracker.

## 🎯 Project Objective

The main objective of this project is to help students manage their money effectively, monitor spending patterns, and develop better saving habits.

## ⚠️ Note

This project uses browser storage for demonstration purposes. Login and signup are not secured for real-world use.
